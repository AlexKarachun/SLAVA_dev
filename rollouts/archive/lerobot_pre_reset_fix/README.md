# Архив: lerobot-семейство до фикса сброса очереди действий

368 папок эпизодов pi0, pi0.5 и SmolVLA, снятых на **Tesla V100** до
06.08.2026. Таблица аннотаций к ним — `../annotation_snapshots/rollout_annotations.jsonl.bak_before_reset_fix_rerun`.

**Для метрик не годятся ни в каком виде.** Очередь действий политики не
сбрасывалась между эпизодами: хвост чанка предыдущего эпизода доигрывался в
начале следующего. Эпизоды при этом шли сгруппированно по вариантам
инструкции, то есть контаминация течёт ровно по измеряемой оси — по языку.
Исправлено добавлением `/reset` у model-серверов, все затронутые эпизоды
пересняты на 2×RTX 3090 и лежат в `final/pilot_v0/`.

Не удалены потому, что это единственная запись о том, что делали
скомпрометированные прогоны: если позже понадобится показать, чем именно
отличается контаминированный сбор, восстановить его будет не из чего.

Подробности бага — `.claude/skills/slava-lerobot-policies`.
