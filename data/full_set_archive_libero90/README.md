# Архив: сцены libero_90

Отложены 08.08.2026. Причина не в качестве сцен, а в том, что **ни один наш
чекпойнт не дообучен на сьюте `libero_90`**: у OpenVLA-OFT это видно прямо в
имени (`...-libero-spatial-object-goal-10`), а все опубликованные базовые линии
в `data/published_baselines.json` — по Spatial/Object/Goal (у pi0.5 плюс Long).
SR на этих сценах был бы около нуля по причине, не связанной с языком, и Δlang
на них не значил бы ничего.

Здесь 270 сцен и их картинки. Если появится чекпойнт, дообученный на
`libero_90`, набор можно вернуть — данные корректны, менять их не надо.
Разбор — `docs/FULL_SET_PLAN.md`, раздел «Те ли это сцены».
