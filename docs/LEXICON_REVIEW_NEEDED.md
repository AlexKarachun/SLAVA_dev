# Сложные случаи object lexicon

После последних решений пользователя остался один содержательно неоднозначный
объект.

## `glazed_rim_porcelain_ramekin`

- Metadata: `porcelain ramekin`.
- На рендере объект похож одновременно на небольшую миску и на порционную форму
  для запекания.
- Сейчас: `canonical_name_ru=формочка`,
  `allowed_synonyms_ru=форма для запекания`.

Нужно выбрать наиболее естественное слово для будущих VLA-инструкций:
`формочка`, `форма для запекания` или `миска`.

## Принятые правила

- `visual_attributes_*` содержит только короткие визуально проверяемые признаки,
  необходимые для различения объектов в VLA-сцене.
- Если форм-фактор упаковки не определяет ее содержимое однозначно,
  `semantic_identity_visually_recoverable=no`.
- `akita_black_bowl` считаем черной миской.
- Основной цвет `flat_stove` — серый.
- Основной цвет `plate` — белый.
- `wine_rack` называем `винная стойка`; допустимый синоним —
  `винный стеллаж`.
- Желтая сушилка не является частью раковины и не входит в ее описание.
