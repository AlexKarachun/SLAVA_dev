# Очередь автономной смены

Одна строка — одна единица работы размером в один коммит. Оркестратор
(`scripts/night_shift.sh`) берёт первую незакрытую, запускает под неё отдельную
сессию со свежим контекстом и отмечает результат:

- `- [ ]` — не начата
- `- [x]` — сделана (есть коммит, дерево чистое)
- `- [!]` — заблокирована, причина в конце строки и в `rollouts/night_shift/`

Формулировать задачу надо так, чтобы она была проверяема без человека:
«обновить X по правилу Y, тесты зелёные» — да; «улучшить отчёт» — нет.
